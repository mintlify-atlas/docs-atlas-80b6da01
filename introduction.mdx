## What is Kairo?

Kairo is the intelligent learning ecosystem for [Riwi](https://riwi.io)'s 11-month software development bootcamp. It analyzes each student's technical performance and soft skills to generate dynamic, personalized 4-week growth paths — ensuring no Coder gets left behind.

The platform serves two types of users:

<CardGroup cols={2}>
  <Card title="Coders" icon="graduation-cap" href="/features/coder-dashboard">
    Bootcamp students who receive AI-generated learning plans, practice exercises, and feedback tailored to their pace and learning style.
  </Card>
  <Card title="Team Leaders (TL)" icon="users" href="/features/tl-dashboard">
    Instructors and mentors who get a real-time analytics dashboard to identify at-risk students before academic failure occurs.
  </Card>
</CardGroup>

## Architecture overview

Kairo is a distributed system with three independently deployed services:

| Service | Technology | Responsibility |
|---|---|---|
| **API Gateway** | Node.js + Express | Authentication, business logic, routing |
| **AI Microservice** | Python + FastAPI | LLM inference, plan generation, RAG search |
| **Database** | PostgreSQL (Supabase) | Persistent storage, RLS policies |

The frontend is a Multi-Page Application (MPA) served via static hosting (e.g. GitHub Pages), communicating with the Node.js gateway over REST.

## Tech stack

**Frontend**
- HTML5, CSS3, Vanilla JavaScript
- Bootstrap 5 for responsive layout
- EJS templates for server-side rendering

**Backend**
- Node.js + Express 5 (API Gateway)
- Python 3 + FastAPI (AI Microservice)
- Passport.js for OAuth (Google, GitHub)

**AI / ML**
- Groq-hosted Qwen2.5-7B-Instruct model
- LangChain for prompt orchestration and JSON output validation
- `all-MiniLM-L6-v2` embeddings (384 dimensions) for semantic resource search

**Database**
- PostgreSQL 14+ hosted on Supabase
- Row-Level Security (RLS) policies
- Custom ENUM types for roles, risk levels, and AI agents
