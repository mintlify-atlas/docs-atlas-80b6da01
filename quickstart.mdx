<Note>
  Kairo requires all three services running simultaneously: the Node.js API gateway, the Python AI microservice, and the frontend. This guide gets the two backends up first.
</Note>

## Prerequisites

Before you start, make sure you have the following installed:

- **Node.js 18+** — [nodejs.org](https://nodejs.org)
- **Python 3.10+** — [python.org](https://www.python.org)
- **PostgreSQL via Supabase** — a free project at [supabase.com](https://supabase.com) works fine
- **Git**

Verify your versions:

```bash
node --version   # v18.0.0 or higher
python3 --version  # 3.10.0 or higher
```

## Get started

<Steps>
  <Step title="Clone the repository">
    ```bash
    git clone https://github.com/Riwi-Project-C6/Learning-Platform.git
    cd Learning-Platform
    ```
  </Step>

  <Step title="Configure environment variables">
    Create two `.env` files — one for each backend service.

    **`backend-node/.env`**

    ```env
    # SERVER CONFIGURATION
    PORT=3000
    NODE_ENV=development

    # SECURITY & SESSIONS
    SESSION_SECRET=your_session_secret

    # DATABASE (POSTGRESQL - SUPABASE)
    DB_HOST=your_host
    DB_PORT=5432
    DB_NAME=your_name
    DB_USER=postgres.your_user
    DB_PASSWORD=your_password
    DATABASE_URL=your_database_url

    # SUPABASE CONFIG
    SUPABASE_URL=your_supabase_url
    SUPABASE_ANON_KEY=your_anon_key

    # FRONTEND CONNECTION
    FRONTEND_URL=http://127.0.0.1:5500/frontend

    # PYTHON CONNECTION
    PYTHON_API_URL=http://localhost:8000

    # SOCIAL AUTH - GITHUB
    GITHUB_CLIENT_ID=your_client
    GITHUB_CLIENT_SECRET=your_client_secret

    # SOCIAL AUTH - GOOGLE
    GOOGLE_CLIENT_ID=your_client
    GOOGLE_CLIENT_SECRET=your_client_secret

    # AUTHENTICATION SMTP
    SMTP_HOST=smtp.gmail.com
    SMTP_PORT=465
    SMTP_SECURE=true
    SMTP_USER=your_email
    SMTP_PASS=your_app_password
    SMTP_FROM="Kairo <your_email>"

    # API KEY AI
    RIWI_IA_KEY=your_ia_key
    ```

    **`backend-python/.env`**

    ```env
    # PYTHON CONFIGURATION
    PORT=8000
    ENV=development

    # OPENAI-COMPATIBLE API (Groq)
    OPENAI_API_KEY=your_api_key

    # MODEL IA
    MODEL_NAME=your_model

    # SUPABASE CONFIG
    SUPABASE_URL=your_supabase_url
    SUPABASE_SERVICE_KEY=your_service_key

    # BACKEND NODE PORT
    NODE_URL=http://localhost:3000

    # FRONTEND PORT
    FRONTEND_URL=http://localhost:5500
    ```

    <Warning>
      `FRONTEND_URL` in `backend-node/.env` must match the **exact origin** where the frontend is hosted — including protocol, domain, and port. A mismatch will cause the Node.js CORS middleware to block all frontend requests. For example, `http://127.0.0.1:5500` and `http://localhost:5500` are treated as different origins.
    </Warning>
  </Step>

  <Step title="Start the Node.js gateway">
    Open a terminal, navigate to `backend-node`, install dependencies, and start the dev server:

    ```bash
    cd backend-node
    npm install
    npm run dev
    ```

    A successful start prints:

    ```
    🚀 KAIRO API GATEWAY STARTED SUCCESSFULLY
    📡 URL      : http://localhost:3000
    ```
  </Step>

  <Step title="Start the Python AI microservice">
    Open a second terminal and navigate to `backend-python`.

    <CodeGroup>

    ```bash Linux / macOS
    cd backend-python
    python3 -m venv env
    source env/bin/activate
    pip install -r requirements.txt
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    ```

    ```powershell Windows
    cd backend-python
    python -m venv env
    env\Scripts\Activate.ps1
    pip install -r requirements.txt
    uvicorn main:app --host 0.0.0.0 --port 8000 --reload
    ```

    </CodeGroup>

    A successful start logs:

    ```
    INFO: Kairo AI Service v2.3.0  |  starting up
    INFO: Uvicorn running on http://0.0.0.0:8000
    ```
  </Step>

  <Step title="Start the frontend">
    Open a third terminal in the repository root. The recommended method is **VS Code Live Server** on port 5500. Alternatively:

    ```bash
    npx serve -p 5500
    ```

    Make sure `FRONTEND_URL` in `backend-node/.env` reflects whichever URL Live Server uses.
  </Step>

  <Step title="Verify both services are running">
    With both backends started, run the health checks:

    <CodeGroup>

    ```bash Node.js gateway
    curl http://localhost:3000/api/health
    ```

    ```bash Python AI microservice
    curl http://localhost:8000/health
    ```

    </CodeGroup>

    Expected responses:

    ```json Node.js gateway
    {
      "status": "active",
      "uptime": 12.34,
      "database": { "connected": true, "timestamp": "2026-03-15T..." }
    }
    ```

    ```json Python AI microservice
    {
      "status": "online",
      "service": "Kairo AI Engine",
      "version": "2.3.0",
      "model": "llama-3.3-70b-versatile",
      "embeddings": "all-MiniLM-L6-v2 (384d)",
      "environment": "development"
    }
    ```

    If either health check returns an error, confirm the `.env` values are correct and the database schema has been applied. See [Database setup](/setup/database) for details.
  </Step>
</Steps>
